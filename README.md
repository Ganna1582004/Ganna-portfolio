## 🌟 Key Features

1. **Bilingual Support (English & Arabic)**
   - Smooth toggle between English (LTR) and Arabic (RTL).
   - Dynamic `dir="rtl"` and `dir="ltr"` attribute switching.
   - Tailored Arabic typography with Google Cairo & Alexandria fonts, and English typography with Plus Jakarta Sans.
   - Comprehensive translation for every section, project case study, timeline, and form.

2. **Dark & Light Mode Switcher**
   - Tailwind `dark` class toggling with local storage persistence and system preference detection.
   - Sleek Dark Theme: Deep Slate-950 & Zinc-900 background with accents in Violet, Indigo, and Cyan.
   - Clean Light Theme: Slate-50 background with soft glassmorphic shadows and crisp text contrast.

3. **No Personal Photos (Abstract Vector & Glassmorphism Design)**
   - Features an interactive **Figma Canvas vs. React Code** inspector widget in the Hero section.
   - Abstract vector patterns, glowing ambient gradients, and custom SVG mockups for each project.

4. **Featured Projects & Case Studies**
   - **Dermalyze (Graduation Project)**: AI Skin Cancer Detection Platform (AI + React + UI/UX).
   - **Food Delivery App**: Route UX Training Project with 3-step checkout optimization.
   - **Reading App**: Route UX Training Project with community annotations and custom reader themes.
   - Interactive deep-dive modal showcasing deliverables, metrics, and tools.

5. **Complete Sections**
   - **Navbar**: Sticky glassmorphism header with logo, smooth-scroll links, language toggle, theme toggle, and mobile drawer.
   - **Hero**: Catchy introduction, AI background badge, CTAs, and interactive design/code card.
   - **About Me**: Narrative connecting Computer Science (AI Major) at Thebes Academy with UX research & React development.
   - **Skills Grid**: Categorized into UI/UX Design, Front-End & Programming, and Tools & Workflow.
   - **Experience & Education Timeline**: Highlighting DEPI Front-End traineeship, Route UX training, and Thebes Academy B.Sc.
   - **Contact & Footer**: Contact cards (email with one-click copy, direct phone & WhatsApp, location in Al-Maadi), interactive contact form with validation, social links, and dynamic copyright.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or newer)
- npm

### Installation
```bash
# Clone or navigate to the project directory
cd portfolio

# Install dependencies (if not already installed)
npm install
```

### Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` (or the port indicated in terminal).

### Production Build
```bash
npm run build
```
Generates an optimized production build in the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```
